# Ozeki Corporate 0.1.0

Initial release of a lightweight corporate WordPress block theme.

## Highlights

- Native WordPress blocks, templates, patterns and Global Styles.
- Optional Japanese Refined typography for Japanese and mixed-language content.
- Responsive layouts, mobile navigation and visible keyboard focus.
- Classic content image sizing, readable preformatted text and post pagination.
- Local system fonts; no external CDN, analytics or companion plugin required.

## Requirements

- WordPress 6.6 or later.
- PHP 8.1 or later.
- GPL-2.0-or-later.

## Installation

Download `ozeki-corporate-0.1.0.zip` from the release assets and upload it through
Appearance > Themes > Add New > Upload Theme. GitHub's automatic Source code
archives are not the tested distribution package.

Configure the theme in Appearance > Editor. The separate fictional-company demo
content and photographs are not automatically imported by installing the theme.

## Verification scope

Theme Check and representative PHP/WordPress runtime checks were performed.
Browser audits covered Edge, Firefox and Playwright WebKit, with official Theme
Unit Test content. Page-number navigation, password-protected posts and comment
reply/cancel/submission were exercised on the local ZIP installation.

The user reported basic iPhone Safari and VoiceOver operation. This is not a claim
of complete WCAG conformance or comprehensive screen-reader usability. Mac Safari
and the full manual Theme Unit Test checklist remain unverified.
