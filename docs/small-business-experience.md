# Small-business starter experience

## Product goal

Help a small company or independent professional create a credible business
website without hiring a designer or adapting a blog-oriented layout.
The acceptance question is: can a first-time user build their own company site
from the distributed ZIP, using ordinary WordPress editing tools?

## Baseline review (2026-09-07)

The current hero has no photograph. Service cards contain instructional
placeholders rather than finished example descriptions. The environment supplies
the richer Northstar Engineering showcase separately. Its pages, photographs,
navigation and saved template customizations are not installed by the theme.
The public showcase therefore does not prove the fresh-install experience.

## Required improvements

- Provide an attractive photo-supported starter composition, not only empty slots.
- Include coherent fictional example copy for introduction, services, strengths,
  company information and contact guidance; identify examples as fictional.
- Offer reusable native block patterns for the homepage and supporting pages.
- Supply locally bundled sample images with documented provenance and compatible
  redistribution terms. Explain how to replace images and their alternative text.
- Make image, text, navigation and style replacement understandable without code,
  a page builder, fixture scripts or database manipulation.
- Explain that Japanese Refined changes typography, not document language.
- Explain contact setup honestly: the theme does not itself send inquiries.
- Do not automatically create posts, pages, media or overwrite existing content.
- Keep existing sites and the published release unchanged during this review.

## Acceptance checks on a fresh ZIP installation

All items below are pending for the improved starter experience.

- [ ] Fresh installation without environment fixtures or saved theme settings.
- [ ] Initial desktop and mobile composition is complete and readable.
- [ ] User can replace site identity, hero image and introductory copy.
- [ ] User can adapt services, company information and contact guidance.
- [ ] User can create supporting pages from supplied patterns and link navigation.
- [ ] Save and reload preserve valid editable blocks without recovery prompts.
- [ ] English and Japanese content, including long headings, remain usable.
- [ ] Images and patterns required by the instructions are present in the ZIP.
- [ ] Instructions reproduce the intended result without developer-only tooling.
- [ ] Keyboard, focus, contrast and image alternatives checked after changes.
- [ ] Relevant changed layouts and interactions checked in Mac Safari.

Passing previous runtime tests or viewing the AWS showcase does not automatically
complete these checks. Record the tested ZIP, environment and observed results.
Keep broader accessibility assessment distinct from limited manual checks.
